# pearkit

**One set of React components for React Native _and_ Electron**, styled with Tailwind (via [NativeWind](https://www.nativewind.dev)) and themeable at runtime. pearkit is the UI layer of the PearDrive apps — the components here were broken down from the PearDrop desktop design.

## How it's built

| Layer | What it does |
| --- | --- |
| **React Native primitives** | Every component is made of `View`, `Text`, `Pressable`, `TextInput` and `react-native-svg`. On iOS/Android they're native; in Electron they render to the DOM through `react-native-web`. |
| **Tailwind via NativeWind** | Components are styled with `className`. The same classes compile to CSS on the web and to native styles on mobile. Every component accepts `className` and later classes win (`tailwind-merge`). |
| **Runtime themes** | `ThemeProvider` turns a theme object into `--pk-*` CSS variables. The Tailwind preset maps colours to those variables, so `bg-primary` follows the active theme. Themes can be switched or nested without a rebuild. |

## What's inside

- **Foundations** — colour tokens, type scale, 37 icons (22 exported straight from the Figma file).
- **Components** — Button, IconButton, Tooltip, StatusPill / StatusDot, CountBadge, ProgressBar, SearchField, Thumbnail, Avatar, PeerChip, QRCode, LinkField, KeyValueList, EmptyState, TextField, Dialog, Card, Divider, Kbd, SectionLabel, Spacer, Gradient, WindowControls, Sidebar (resizable, collapsible), Toolbar, PaneHeader, AppWindow / Pane.
- **Patterns** — the PearDrop building blocks: ShareRow, FileHeader, TransferCard, ShareLinkCard, NetworkStatusCard, DangerZone.
- **Layouts** — full desktop and mobile screens composed only from the above. They double as living examples and catch regressions when a component changes.

Use the **Theme** switcher in the toolbar to see every story in Pear Dark, Pear Light, or a custom theme.
